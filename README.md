# Python projects

My collection of Python exercises and small projects, from variables and loops to an object-oriented battle simulator. The original filenames preserve the order of my learning.

## Start here

| Project | What I practiced |
| --- | --- |
| [HSR Lite](19.%20HSR_Lite%20%28MEGA%20PROJECT%29.py) | Classes, inheritance, character health, attacks, healing, and turn-based battle simulation. A fan learning project inspired by Honkai: Star Rail. |
| [Hangman](11.%20hangman_game%20%28BIG%20PROJECT%29.py) | Game loops, strings, guesses, and game state. |
| [Contact list](17.%20contact_list.py) | Managing entries through a command-line interface. |
| [Rock paper scissors](14.%20rock%20paper%20scissor%20game.py) | Input handling, randomness, and conditions. |
| [Spiral grid](21.%20spiral_grid.py) | Nested loops and matrix traversal. |

The other files include a quiz, number guessing games, calculators, pattern exercises, and an alarm experiment.

## Run a project

Install Python 3, open this folder in a terminal, and run a script, for example:

```sh
python "19. HSR_Lite (MEGA PROJECT).py"
```

Keep `div.py` beside the other scripts because some exercises import it. The alarm experiment uses `winsound` and requires Windows. Some scripts ask for terminal input.

## Learning notes

These are historical learning projects, with rough edges and unfinished ideas. Syntax checks do not establish that every game or input path works correctly. Empty placeholders and a machine-specific batch file-renaming utility are omitted from this public collection.

Resources include [Bro Code's Python course](https://youtu.be/ix9cRaBkVe0). I have also used GitHub Copilot and ChatGPT for explanations and debugging support; these projects document practice rather than a claim that every line was written without help.
